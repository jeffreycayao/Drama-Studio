Top findings

What to fix first, in the order I would do it.

Broken or misleading

  1. Send Feedback goes nowhere. Fixed in 0.6.1: the form is hidden until a feedback service or support email exists; the page points to Discord and copies system info.
  2. The Assistant shows raw tool output. Fixed in 0.6.1: tool output a model echoes into its reply is folded behind a "details" toggle.

Hidden features

  1. The strongest AI tools are right-click only. Fixed in 0.6.1: an "AI tools" button on the selected clip and an AI row in the Inspector quick actions (also for linked video/audio pairs).
  2. Pro editing tools are right-click only. Fixed in 0.6.1: an Edit row (mask, compound clip, paste attributes, match frame, move by offset) and label colours in quick actions.
  3. The prompt library is hard to find. Fixed in 0.6.1: Prompts button in the top bar, next to Cast.
  4. Setup Doctor and the guided tour sit two menus deep. Fixed in 0.6.1: Tour on the welcome screen next to the setup check; Check my setup and Take the guided tour at the top of Help.
  5. Import pack only shows in Generate. Fixed in 0.6.1: package button and right-click item in the Assets panel.

Controls that need a redesign

  1. Timeline toolbar: about 30 tiny buttons in one row. Fixed in 0.6.2: Tools, Add and Edit groups plus Snap and Ripple; everything else in a More menu; each tool has its own icon; labels when the timeline is wide.
  2. Top bar: 12 items compete. Fixed in 0.6.2: Cast, Credits, AI jobs and ComfyUI in one status group; Learn AI is quiet gold text; an open Assistant is an outline, so the active tab is the one solid accent.
  3. "Delete Disk / Project Only" always on screen. Fixed in 0.6.2: each delete confirmation asks Keep the file (default) or Also delete the file.
  4. Track headers: unlabeled S, M, P, names cut off. Fixed in 0.6.2: wider headers, icons with tooltips (target / headphones for solo, crosshair for the cut target), full name on hover.
  5. Idea Pad opens on an empty canvas. Fixed in 0.6.2: Three-act short and Micro-drama episode templates on an empty board.

Under-used or not finished

  1. Discover tab separate from Help. Fixed in 0.6.2: now Help › Watch (the welcome button is called Watch). The catalog is still empty until tutorials are published.
  2. ComfyUI tab in the beginner flow. Fixed in 0.6.2: renamed Advanced and moved to the end of the top bar.
  3. Companion extension and browser link: Generate › AI Sites sends prompts and references to 13 sites, and "Send to Drama Studio" brings results back. The side panel now opens on a Sites tab listing every site and what works there (it used to show only the Grok batch tool). Grok Imagine has an on-page Send button and sets the shape itself; the other 12 are still right-click only and shape by hand. Each site needs a live check, since site pages change.
  4. Motion Studio: built. One guided "AI does the edit" flow on its own top tab. Next: a storyboard view and checks that look at the rendered cut.
  5. Hidden workspaces: the Agent, Flow AI and MoGraph tabs existed but were switched off. Removed after the 0.6.7 audit: about 7,000 unreachable lines gone; projects with Flow AI data still open.
  6. Help Center in Japanese: the UI is translated, but the guides are not. Fixed in 0.6.5: every guide, diagram and the Help search follow the app language.
