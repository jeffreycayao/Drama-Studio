# Third-party notices

Drama Studio Companion bundles the following third-party software. Everything
is packaged inside the extension; nothing is loaded from a remote service at
runtime.

## Fonts

The same three families as the Drama Studio desktop app, bundled as local
WOFF2 files through Fontsource packages (Fontsource is a build-time source
only):

- **Inter** (`@fontsource-variable/inter` 5.3.0): Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter).
- **Sora** (`@fontsource-variable/sora` 5.3.0): Copyright 2019 The Sora Project Authors (https://github.com/sora-xor/sora-font).
- **JetBrains Mono** (`@fontsource-variable/jetbrains-mono` 5.3.0): Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).

Each font is distributed under the SIL Open Font License 1.1, reproduced below.

## Libraries

- **Tabler Icons for Vue** (`@tabler/icons-vue` 3.46.0): locally bundled SVG icon components, MIT license. The full notice is in [`licenses/TABLER-LICENSE.txt`](licenses/TABLER-LICENSE.txt).
- **SheetJS Community Edition** (`xlsx` 0.20.3): local parsing of user-selected XLS, XLSX and CSV prompt files, Apache License 2.0. The full license is in [`licenses/SHEETJS-APACHE-2.0.txt`](licenses/SHEETJS-APACHE-2.0.txt).
