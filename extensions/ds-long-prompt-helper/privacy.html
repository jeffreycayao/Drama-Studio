Privacy Policy

Last Updated: March 5, 2026

Overview

Sellify™ AI Connector ("the Extension") is a Chrome browser extension that automatically prefills AI chat prompts across multiple platforms (Google Gemini, ChatGPT, Claude, Perplexity AI, and Manus) using URL hash fragments, query parameters, or storage API.

This Privacy Policy explains how the Extension handles data and protects your privacy.

We do NOT collect any user data.

The Extension operates entirely locally in your browser and does not transmit any information to external servers.

Data Collection

The Extension does NOT collect any personal or usage data.

What We Do NOT Collect:

  • Personal information (name, email, address, etc.)
  • User behavior or browsing history
  • AI prompts or conversations
  • Cookies or tracking identifiers
  • Analytics or usage statistics
  • Login credentials or authentication data
  • IP addresses or location data
  • Device information or system data

How the Extension Works

The Extension operates entirely within your browser and performs the following actions locally:

  1. Reads URL parameters: Extracts #prompt=, #q=, ?prompt=, or ?q= from the current page URL
  2. Checks local storage: Looks for pending prompts in chrome.storage.local (auto-expires after 5 minutes)
  3. Locates input elements: Finds platform-specific input boxes on supported AI platforms
  4. Prefills prompts: Automatically fills the input box with the prompt text
  5. Clears storage: Removes stored prompts after successful injection

All processing happens locally in your browser. No data is sent to external servers.

Temporary Storage

The Extension may temporarily store prompts in chrome.storage.local for advanced automation workflows. This storage:

  • Only stores prompt text, target platform, and timestamp
  • Auto-expires after 5 minutes
  • Auto-clears after successful injection
  • Stays local in your browser (never transmitted)
  • Does not contain any personal information
  • Is not used for analytics or tracking

This temporary storage enables the Storage API transport method for bypassing URL length limitations and CloudFront/WAF restrictions.

Permissions

The Extension requires the following permissions to function:

Host Permissions

The Extension requires access to the following domains:

  • gemini.google.com - Google Gemini
  • chat.openai.com, chatgpt.com - ChatGPT
  • claude.ai - Anthropic Claude
  • perplexity.ai - Perplexity AI
  • manus.im - Manus AI
  • grok.com - Grok AI

These permissions allow the Extension to detect when you visit these platforms, read URL parameters/hash fragments, and interact with input boxes.

Storage Permission

Access to chrome.storage.local for:

  • Storing pending prompts temporarily (max 5 minutes)
  • Enabling the Storage API transport method
  • Bypassing URL length limitations

No other websites, domains, or external services are accessed.

Third-Party Services

The Extension does not integrate with, communicate with, or share data with any third-party services, analytics platforms, or external servers.

The Extension only interacts with the AI platforms you visit directly (Gemini, ChatGPT, Claude, Perplexity, Manus) to prefill input boxes locally in your browser.

Data Security

Since the Extension does not collect, store permanently, or transmit any user data, there are no data security concerns related to user information.

All operations are performed locally in your browser, and any temporary storage (chrome.storage.local) is:

  • Encrypted by Chrome's built-in security
  • Only accessible by the Extension
  • Auto-expired after 5 minutes
  • Never transmitted over the network

Supported Platforms

The Extension works on the following AI platforms:

  • Google Gemini (gemini.google.com)
  • ChatGPT (chat.openai.com, chatgpt.com)
  • Claude (claude.ai)
  • Perplexity AI (perplexity.ai)
  • Manus AI (manus.im)
  • Grok AI (grok.com)

You must be logged into each platform for the Extension to work. The Extension does not access your login credentials or authentication data.

Children's Privacy

The Extension does not knowingly collect information from children under 13 years of age. Since we do not collect any user data at all, this policy applies to all users regardless of age.

Your Rights

Since the Extension does not collect or store any personal data, there is no user data to access, modify, or delete. All operations are performed locally in your browser.

You can:

  • Uninstall the Extension at any time through Chrome's extension settings
  • Clear chrome.storage.local data through Chrome's developer tools
  • Disable the Extension temporarily without uninstalling
