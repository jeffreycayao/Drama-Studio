Welcome to Sellify™ AI Connector Support

Sellify™ AI Connector is a Chrome extension that automatically prefills AI chat prompts across multiple platforms using URL hash fragments, query parameters, or storage API. This page provides comprehensive support and documentation.

Supported Platforms

  • Google Gemini (gemini.google.com)
  • ChatGPT (chat.openai.com, chatgpt.com)
  • Claude (claude.ai)
  • Perplexity AI (perplexity.ai)
  • Manus AI (manus.im)
  • Grok AI (grok.com)

How to Use

Method 1: Hash Fragments RECOMMENDED

Use hash fragments (#) to bypass CloudFront/WAF restrictions. Hash fragments are never sent to the server - they stay in the browser!

Examples:

https://manus.im/app/#prompt=Your+very+long+prompt+here
https://gemini.google.com/#q=Your+prompt+here
https://chat.openai.com/#prompt=Your+prompt+here
https://claude.ai/#q=Your+prompt+here
https://www.perplexity.ai/#prompt=Your+prompt+here
https://grok.com/#q=Your+prompt+here

Benefits:

  • Unlimited prompt length (browser limit ~2MB)
  • Bypasses CloudFront/WAF blocks
  • Perfect for Manus platform
  • Shareable URLs
  • Client-side only (never sent to server)

Method 2: Query Parameters

Traditional method using query parameters (?) in the URL.

Examples:

https://gemini.google.com/?q=Your+prompt+here
https://chat.openai.com/?q=Your+prompt+here
https://claude.ai/?prompt=Your+prompt+here
https://grok.com/?q=Your+prompt+here

Best for:

  • Short prompts (less than 2000 characters)
  • Backward compatibility
  • Platforms without CloudFront restrictions

Limitations:

  • URL length limits (~2000 characters)
  • CloudFront may block long URLs on Manus

Method 3: Storage API

For programmatic access from external tools, bookmarklets, or Chrome extensions.

Example:

chrome.storage.local.set({
    pendingPrompt: {
        text: 'Your prompt',
        platform: 'manus',
        timestamp: Date.now()
    }
}, () => {
    window.open('https://manus.im/app', '_blank');
});

Best for:

  • Automation workflows
  • External tool integration
  • Very long prompts

Features:

  • Unlimited prompt length
  • Auto-expires after 5 minutes
  • Auto-clears after injection
  • Platform validation

Troubleshooting

Extension not working?

  1. Verify the extension is installed and enabled in Chrome
  2. Check that you're on a supported AI platform
  3. Ensure the URL contains #prompt=, #q=, ?prompt=, or ?q=
  4. Refresh the page after adding the prompt parameter
  5. Check browser console for [Sellify Connector] logs

Getting 403 errors on Manus?

This means you're using query parameters (?) with a long prompt. Switch to hash fragments (#) instead:

❌ https://manus.im/app/?prompt=LONG_TEXT
✅ https://manus.im/app/#prompt=LONG_TEXT

Prompt not injecting?

  • Make sure you're logged into the AI platform
  • Verify the prompt is properly URL-encoded
  • Check if storage prompt has expired (>5 minutes)
  • Try refreshing the page
  • Disable other extensions that might interfere

Hash fragment not working?

  • Ensure you're using # not ?
  • Check browser console for extension logs
  • Verify the extension is enabled
  • If you change the hash after page load, refresh the page

Frequently Asked Questions

Does this extension collect my data?

No. The extension does not collect, store, or transmit any user data. All processing happens locally in your browser. Prompts stored via Storage API auto-expire after 5 minutes and are cleared after injection.

Do I need to be logged into the AI platforms?

Yes. The extension only prefills the input box. You must be logged into each AI platform for it to work.

Can I use this for automation?

Yes! Use the Storage API method for programmatic access from external tools and scripts.

What's the maximum prompt length?

  • Hash fragments: Unlimited (browser limit ~2MB)
  • Query parameters: ~2000 characters (varies by platform)
  • Storage API: Unlimited

Why use hash fragments over query parameters?

Hash fragments are never sent to the server, so they bypass CloudFront/WAF restrictions and have no length limits. They're especially important for Manus platform.

Can I share prompt URLs with my team?

Yes! URLs with hash fragments or query parameters are fully shareable. Storage API prompts are not shareable (they require programmatic setup).
