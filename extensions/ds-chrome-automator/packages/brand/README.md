# Paks Tools Faceless automations brand

Shared, locally bundled typography and design tokens for every app in the monorepo.

```css
@import '@faceless-automations/brand/styles.css';
```

- Instrument Serif: display and narrative headings
- Manrope: body text, controls, and navigation
- IBM Plex Mono: eyebrows, metadata, and numbers

Font files are emitted by each app's production bundler as same-origin WOFF2 assets. Remote font stylesheets and runtime font downloads are prohibited. See [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md) for licensing.
